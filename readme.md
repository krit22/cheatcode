# CheatCode CLI

> Stealth CLI AI Assistant powered by OpenRouter.

## 🚀 One-Line Installation for Linux

Install `cheatcode` instantly on Linux without needing Node.js or `npm`:

```bash
curl -fsSL https://raw.githubusercontent.com/krit22/cheatcode/main/install.sh | bash
```

---

## 🛠️ Usage

```bash
cheatcode
```

### Options

```bash
cheatcode --help
```

---

## 📦 Building Standalone Binaries Locally

```bash
npm run compile
```

Outputs standalone executables in `bin/`:
- `bin/cheatcode-cli-linux` (Linux)
- `bin/cheatcode-cli-win.exe` (Windows)
- `bin/cheatcode-cli-macos` (macOS)
